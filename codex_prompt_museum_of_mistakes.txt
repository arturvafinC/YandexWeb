================================================================================
1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА
================================================================================

Название проекта:
«Музей ошибок»

Полное название:
«Музей ошибок: веб-приложение для хранения, анализа и повторения учебных ошибок»

Суть:
Пользователь регистрируется в системе, добавляет свои учебные ошибки, указывает предмет, тему, тип ошибки, свой неправильный ответ, правильный ответ, объяснение и статус. Также пользователь может прикрепить изображение задания. Система помогает видеть слабые места, возвращаться к ошибкам для повторения и отслеживать прогресс исправления ошибок.

Главная ценность проекта:
Это не просто CRUD-сайт, а инструмент для осознанной работы над ошибками при подготовке к экзаменам, контрольным, олимпиадам или изучении новых тем.

3. РОЛИ ПОЛЬЗОВАТЕЛЕЙ

3.1. Гость

Гость может:
- открыть главную страницу;
- прочитать описание проекта;
- открыть страницу регистрации;
- открыть страницу входа.

- удалять ошибки;

3.2. Авторизованный пользователь

- открыть личный кабинет;
- добавить ошибку;
- посмотреть список своих ошибок;
- открыть детальную страницу своей ошибки;

- удалить свою ошибку;

- пользоваться REST API для своих ошибок;

6. REST API
================================================================================

Сделать отдельный Blueprint:
/api

API работает с JSON.

Эндпоинты:

GET /api/mistakes
Возвращает список ошибок текущего пользователя.

GET /api/mistakes/<id>
Возвращает одну ошибку текущего пользователя.

POST /api/mistakes
Создаёт ошибку из JSON.

PUT /api/mistakes/<id>
Полностью обновляет ошибку.

PATCH /api/mistakes/<id>
Частично обновляет ошибку.

DELETE /api/mistakes/<id>
Удаляет ошибку.

HTTP status codes:
- 200 OK
- 201 Created
- 400 Bad Request
- 401 Unauthorized
- 403 Forbidden
- 404 Not Found
- 500 Internal Server Error

Пример POST JSON:

{
  "title": "Ошибка в квадратном уравнении",
  "subject": "Математика",
  "topic": "Квадратные уравнения",
  "mistake_type": "Ошибка в формуле",
  "status": "Нужно повторить",
  "wrong_answer": "x = 3",
  "correct_answer": "x = -3",
  "explanation": "Ошибка при раскрытии скобок"
}

Если пользователь не авторизован, API возвращает:
{
  "error": "Authentication required"
}
со статусом 401.

Если ошибка чужая:
{
  "error": "Forbidden"
}
со статусом 403.

Если ошибка не найдена:
{
  "error": "Mistake not found"
}
со статусом 404.
